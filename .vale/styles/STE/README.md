# STE style

An approximation of [ASD-STE100](https://www.asd-ste100.org/) rules that Vale can check.
It is not a certification: the official approved-word dictionary is licensed by ASD and
is not bundled here. Authors and reviewers must still follow the full specification.

Checked automatically: sentence length, passive voice, contractions, a list of words with
simpler STE alternatives, semicolons. Add words to `Words.yml` when a review finds more.
