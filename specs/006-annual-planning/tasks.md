# Tasks: Annual Planning, Goals and Key Results

**Input**: Design documents in `/specs/006-annual-planning/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/api.md, quickstart.md. Feature 003 is implemented and is a dependency (labels, orphan mark, `create_and_label`).

**Tests**: Required (constitution V). Tests come first inside each phase and must fail before the code that satisfies them.

**Organization**: Phases are the milestones M1 to M8 of plan.md. Inside a phase every task carries the user story it serves. Each phase ends with a completion-criteria task that must pass before the next phase starts.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (other files, no dependency on an unfinished task)
- **[US#]**: user story of spec.md: US1 write goals with key results, US2 link key results to theme projects, US3 flags, US4 create a missing theme, US5 start a new year from year N, US6 edit during the year (retire, restore, history, undo), US7 values and the push, US8 goals become annual only
- Commands use `source /root/tefteri-env.sh` in this session. On a normal machine use `devbox shell`.
- Paths: `backend/` is the Python project, `frontend/` is the Flutter project.
