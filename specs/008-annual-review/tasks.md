# Tasks: Annual Review

**Input**: Design documents in `/specs/008-annual-review/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/api.md, quickstart.md. Features 003, 004, 005, 006 and 007 are built first: the review reads their data (snapshots of 007, plan of 006, counts of 005, labels of 003).

**Tests**: Required (constitution V). Tests come first inside each phase.

**Organization**: Phases are the milestones M1 to M6 of plan.md. Inside a phase every task carries the user story it serves. Each phase ends with a completion-criteria task that must pass before the next phase starts.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (other files, no dependency on an unfinished task)
- **[US#]**: user story of spec.md: US1 each goal and whether its key results were hit, US2 themes that served key results, US3 year split of work, US4 missing months and years with no snapshots, US5 mid-year changes, US6 orphaned themes, US7 start next year, US8 the review replaces the Year view
- Tasks with no story serve the whole feature (migration, checks, docs index)
- Commands use `source /root/tefteri-env.sh` in this session. On a normal machine use `devbox shell`.
- The name of the task app appears only in `adapters/` and in the live test recipes. Other files say "task app".
