# Tasks: Weekly Planning and Review with Milestone Projects

**Input**: Design documents in `/specs/004-weekly-milestones/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/api.md, quickstart.md. Feature 003 is implemented and is the base.

**Tests**: Required (constitution V). Tests come first inside each phase and must fail before the code that satisfies them.

**Organization**: Phases are the milestones M1 to M6 of plan.md. Inside a phase every task carries the user story it serves. Each phase ends with a completion-criteria task that must pass before the next phase starts. The existing weekly flow is changed in place; tasks that change an existing file say so.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (other files, no dependency on an unfinished task)
- **[US#]**: user story of spec.md: US1 commit milestones for the week, US2 create a milestone with a done-state, US3 pick or add tasks, US4 cap warning and outside focus, US5 weekly review numbers, US6 decide on every unfinished milestone (and completion, close and move), US7 rollover count and nudge, US8 old carry and backlog choices
- Commands use `source /root/tefteri-env.sh` in this session. On a normal machine use `devbox shell`.
- Numbers 0020 to 0023 are reserved for the migrations of features 006, 005, 007 and 008. This feature uses `0019_weekly_milestones` only.

## Dependencies and order

- Phase 1 before all others. Phase 2 before Phase 3 (the close service calls the port). Phase 3 before Phase 4. Phase 4 before Phase 5 (the client uses the API). Phase 6 last.
- Inside a phase, tasks marked [P] touch different files and can run together. A task without [P] either touches a file that an earlier task also touches, or needs a result of one. Tests are written first and must fail before the code that satisfies them.
- Inside Phase 3: T036 to T041 before T042 to T051; T042 before T043 to T046; T047 needs T038 and T040; T048 and T049 need T047; T052 last.
- User story dependencies: US1 (picker and commit) is the base for all. US2 and US3 need US1. US4 needs US1. US6 needs US1 and the M2 port. US7 needs US6. US5 needs US6 for the decisions it shows. US8 needs only the migration and the read mapping and can ship with US1.
